# Discussion guidelines

[Flipper Firmware Discussions](https://github.com/flipperdevices/flipperzero-firmware/discussions) are for feature requests and feature voting only. 

The purpose is to help the team prioritize community-driven improvements and bring them into firmware faster.

## Rules

### 1. Feature requests only
- Post only new feature ideas or enhancements.
- Search existing discussions first. Duplicate posts will be closed.
- Provide a clear title, description, use case, and expected benefits.
- Features must align with the project's goals: research and education.

### 2. Voting and feedback
- Upvote features you support.
- Add constructive comments with details or alternatives.
- Do not spam votes, downvote without explanation, or post “+1” comments.

### 3. No off-topic content
- Bug reports and issues → use the [Issues](https://github.com/flipperdevices/flipperzero-firmware/issues) tab.
- Support, questions, or troubleshooting → use the [official Discord Server](https://discord.gg/flipper) or [User Documentation](https://docs.flipper.net/zero) / [Developer Documentation](https://developer.flipper.net).
- Code contributions and pull requests → follow [Contribution Guide](https://github.com/flipperdevices/flipperzero-firmware/blob/dev/CONTRIBUTING.md).
- Off-topic posts will be closed or moved.

### 4. Project alignment
- All features must support legitimate research and education use.
- Proposals involving illegal activities, crime, or misuse will be rejected immediately. See [Code of Conduct](https://github.com/flipperdevices/flipperzero-firmware/blob/dev/CODE_OF_CONDUCT.md) and [Contribution Guide](https://github.com/flipperdevices/flipperzero-firmware/blob/dev/CONTRIBUTING.md).

### 5. Conduct
- Follow the [Code of Conduct](https://github.com/flipperdevices/flipperzero-firmware/blob/dev/CODE_OF_CONDUCT.md) at all times.
- Be respectful and constructive.
- Maintainers may lock, close, or delete threads that violate the rules.

### 6. Good practices
- Use descriptive titles.
- Include examples, mockups, or references where helpful.
- Add images, diagrams, or demos if possible.
- Keep discussions focused.


Thank you for contributing ideas to improve Flipper Zero!
